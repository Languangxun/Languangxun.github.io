# Languangxun.github.io

个人主页与项目文档站（GitHub Pages + Jekyll minima 主题）。

- 站点地址：https://languangxun.github.io
- 首页：`index.md`
- 项目文档：`docs/`（Markdown，带 front matter）
- 自定义样式：`assets/css/style.scss`

新增文档：把 Markdown 放入 `docs/`，在文件开头加上 `layout: page`、`title`、`permalink` 三个字段，提交推送到 `main` 分支后 GitHub Pages 会自动构建。

注意：本项目是文档站，不要提交 API Key、密码、内网地址等敏感信息。
